# NING Chat UI PNG Assets v1

All individual PNG files have transparent backgrounds and contain no text.

- `01_history_icon.png`: history action icon
- `02_header_frame_active.png`: active header action frame
- `03_header_frame_inactive.png`: inactive header action frame
- `04_new_chat_icon.png`: new conversation icon
- `05_chat_icon_active.png`: chat tab icon, active
- `06_chat_icon_inactive.png`: chat tab icon, inactive
- `07_image_icon_active.png`: image tab icon, active
- `08_image_icon_inactive.png`: image tab icon, inactive
- `09_avatar_ning.png`: NING assistant avatar
- `10_avatar_user.png`: user avatar
- `11_bubble_user.png`: user message background
- `12_bubble_assistant.png`: assistant message background
- `13_input_frame.png`: message input background
- `14_send_icon.png`: send icon
- `00_contact_sheet.png`: preview sheet only; it includes filenames for review

The two avatars are extracted from the supplied reference screenshot. Other assets
are clean raster reconstructions based on the screenshot, so no baked-in labels or
message text remain.
