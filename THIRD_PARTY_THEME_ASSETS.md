# NING theme assets

The cyber HUD source material was supplied locally by the project owner from:

- `ning_cyber_hud_clean_assets`
- `ning_cyber_compose_ui`

Only the clean, text-free HUD layers are packaged with the app. Runtime text,
Live2D characters, background animation, scanlines, floor rings, and microphone
state animation are rendered by Android views.
